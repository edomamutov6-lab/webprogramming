# Инструкция: загрузить проект в GitHub

1. Открой GitHub и нажми + → New repository.
2. Назови репозиторий javascript-basics-problem-set.
3. Выбери Public или Private — как требует преподаватель.
4. Создай пустой репозиторий: не добавляй README, .gitignore и лицензию.
5. На странице репозитория открой Add file → Upload files.
6. Перетащи содержимое папки проекта: README.md, package.json, .gitignore и папку src.
   Если папка src не загружается перетаскиванием, создай файл src/solutions.js через Add file → Create new file и скопируй туда содержимое файла с компьютера.
7. Нажми Commit changes.
8. Скопируй ссылку на репозиторий.
9. В Moodle открой PS: JavaScript Basics, нажми Add submission, вставь ссылку на репозиторий и сохрани отправку.

Проверь, что на GitHub видны README.md, package.json, .gitignore и src/solutions.js.
