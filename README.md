# JavaScript Basics — Problem Set 01

Solutions for the Week 5 JavaScript Basics problem set in Web Programming 1.

## Contents
- Beginner level: exercises 1–24 and bonus exercise 25.
- Array problems: all 15 Easy, Medium, and Hard exercises.
- No third-party packages are required.

## Run
Install Node.js, then run from the project root:
    npm start
Or directly:
    node src/solutions.js

The script prints demonstration calls and results to the terminal.

## Notes
- Exercise 18 demonstrates function scope. The ReferenceError is caught so the remaining examples continue.
- reverseArray does not use reverse(), indexOfElement does not use indexOf(), and flattenOnce does not use flat().
- The bonus exercise is included.

Suggested repository name: javascript-basics-problem-set.
